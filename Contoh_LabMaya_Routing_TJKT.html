Teori Media Transmisi & Routing Subnet

1. Pemilihan Media Kabel (Bab 1): Pada perangkat jaringan lama tanpa fitur Auto-MDIX, menghubungkan dua perangkat sejenis (seperti PC ke Router atau Switch ke Switch) memerlukan kabel UTP Cross-Over agar pin TX (Transmit) bertemu dengan pin RX (Receive).

2. Routing Antar-Subnet (Bab 4): Dua jaringan dengan alamat network berbeda (misal 192.168.1.0/24 dan 172.16.10.0/24) tidak dapat berkomunikasi langsung tanpa Router.

3. Peran Default Gateway: Setiap PC wajib mengisi Default Gateway dengan alamat IP interface Router yang terhubung langsung ke segmen jaringan PC tersebut.

Langkah Praktikum Simulasi

  1. Periksa konfigurasi default pada Panel Kiri, lalu klik "Kirim Paket ICMP (Ping PC0 → PC1)" untuk melihat proses komunikasi sukses.
  2. Coba ubah Media Kabel menjadi UTP Straight-Through atau matikan centang no shutdown pada Router, lalu uji kembali untuk melihat bagaimana sistem mendeteksi kegagalan layer fisik.
  3. Coba ubah Gateway PC0 menjadi salah (misal 192.168.1.99) dan amati log proses saat paket berhenti di PC0 karena tidak menemukan pintu keluar menuju subnet lain.
